1. **1b — no sidebar at 390 px.** Phones get a bottom tab bar and Copilot as a full-screen sheet; a 240 px sidebar would leave about 150 px for the page. Ctrl+B is a desktop shortcut.

4. **9b (API) — behind beta's password gate, "not signed in" still answers 403.** Everywhere else (production, beta through the tunnel) it is 401. A request that carries the gate's login gets 403, because any 401 makes the browser forget the gate's login (audit row 9c, fixed on 2026-10-16). An auditor testing the public beta address will therefore still see 403.
